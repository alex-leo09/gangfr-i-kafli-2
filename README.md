# Gangfræði

Námsvefur um kafla 2 í klassískri eðlisfræði: samantekt, formúlur, trikk, undirkaflar 2.1–2.8 með æfingum og reiknivélar með gröfum.

Vefurinn er ein skrá, `index.html`, og þarf ekkert build-skref.

## Birta á GitHub Pages

1. Settu `index.html` og `README.md` í GitHub-repo.
2. Farðu í **Settings → Pages**.
3. Undir **Source** velurðu **Deploy from a branch**, svo `main` og `/ (root)`, og ýtir á **Save**.
